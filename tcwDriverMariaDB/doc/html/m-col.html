SQLMariaClass.Col

Col(SHORT NroCol),STRING

Devuelve el valor de una columna de la fila actual, como texto. Se asigna directo a campos numéricos, de texto o DECIMAL.

Parámetros

ParámetroDescripción
NroColnúmero de columna (1 = la primera del SELECT).

Devuelve

El valor como texto. '' si es NULL o si la columna no existe.

Ejemplo

  CBQ:Cliente = SQLM.Col(7)
  CBQ:Total   = SQLM.Col(8)                         ! '12345.67' -> 12345.67
  CBQ:Fecha   = DEFORMAT(SQLM.Col(2),@d10-)         ! '2026-10-28' -> fecha de Clarion

Observaciones

No tiene límite de largo. Formatos que manda el servidor: fechas aaaa-mm-dd, horas hh:mm:ss, números con punto decimal. Col_Format no se aplica aquí (solo en LoadQueue): para fechas usar DEFORMAT.

Respecto de SQLClass6

No depende del registro de la tabla de trabajo: sin límite de columnas ni de largo.
