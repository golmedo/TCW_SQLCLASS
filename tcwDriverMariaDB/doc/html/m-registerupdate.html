SQLMariaClass.RegisterUpdate / UpdateBuffer

RegisterUpdate(*FileManager MyFm, *KEY MyKey, *? MyField),VIRTUAL
UpdateBuffer(),BYTE,PROC

Heredados de la SQLClass6 (AutoUpdate): RegisterUpdate asocia el objeto a un archivo del diccionario, su clave y el campo de la clave primaria; UpdateBuffer toma el valor de la columna PK_Col de la fila actual y lee ese registro con el FileManager.

Devuelve

UpdateBuffer: False si leyó el registro; True si no lo encontró.

Ejemplo

  SQLM.RegisterUpdate(Access:Clientes,CLI:PorId,CLI:Id)
  SQLM.PK_Col = 1
  IF SQLM.ExecEx('SELECT Id FROM clientes WHERE Saldo > 0',1) = Level:Benign
    LOOP UNTIL SQLM.Next()
      IF NOT SQLM.UpdateBuffer()
        ! CLI:Record tiene el cliente completo
      END
    END
  END
