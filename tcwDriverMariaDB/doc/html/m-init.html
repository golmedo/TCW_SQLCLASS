SQLMariaClass > Conexión

SQLMariaClass.Init

Init(*FILE Archivo, *GROUP Registro, STRING Conexion),BYTE,VIRTUAL

Conecta con el servidor. Tiene la misma firma que en la SQLClass6 para que el código existente (y el que genera el template) no cambie: el archivo y el registro se guardan pero no se usan; no se abre ningún archivo.

Parámetros

ParámetroDescripción
Archivoarchivo de trabajo de la SQLClass (se ignora).
Registrosu registro (se ignora).
Conexioncadena de conexión. Sirve también la de ODBC (ver Cadena de conexión).

Devuelve

Level:Benign (0) si salió bien; Level:Notify (1) si hubo un error (el texto queda en ErrorText()).

Ejemplo

  SQLM.SilentMode = True
  IF SQLM.Init(sqlclass,uSQL:Record,GLO:Conexion)
    MESSAGE('No se pudo conectar: ' & SQLM.ErrorText())
  END

Observaciones

Con SilentMode = False (por defecto) un error de conexión se muestra con STOP. Se puede llamar otra vez para reconectar; cierra la conexión anterior.

Respecto de SQLClass6

Misma firma; no abre ni crea la tabla de trabajo.
