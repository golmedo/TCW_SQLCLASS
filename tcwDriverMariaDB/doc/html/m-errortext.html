SQLMariaClass > Errores y diagnóstico

SQLMariaClass.ErrorText / ErrorCode

nuevo
ErrorText(),STRING
ErrorCode(),LONG

Texto y número del último error del servidor o de la conexión. Útiles con SilentMode = True, cuando la clase no muestra los errores.

Devuelve

Texto con el detalle y el número entre paréntesis, por ejemplo Error en la consulta: Unknown column 'x' in 'field list' (1054). Vacío si la última operación salió bien.

Ejemplo

  SQLM.SilentMode = True
  IF SQLM.ExecEx(L:Query,1)
    L:Estado = 'Error ' & SQLM.ErrorCode() & ': ' & SQLM.ErrorText()
  END

Observaciones

Errores comunes: 1045 usuario o clave, 1049 base inexistente, 1054 columna inexistente, 1146 tabla inexistente, 2003 no se llega al servidor, 2006 / 2013 se cortó la conexión.

Respecto de SQLClass6

Método nuevo: no existe en la SQLClass6.
