SQLMariaClass > Conexión

SQLMariaClass.InitMaria

nuevo
InitMaria(STRING Conexion),BYTE

Conecta con el servidor sin pasar archivo ni registro. Es lo que llama Init por dentro. Usarlo en código nuevo.

Parámetros

ParámetroDescripción
Conexioncadena de conexión (ver Cadena de conexión).

Devuelve

Level:Benign (0) si salió bien; Level:Notify (1) si hubo un error (el texto queda en ErrorText()).

Ejemplo

  IF SQLM.InitMaria('Server=192.168.0.10;Database=gestion;User=app;Password=' & L:Clave)
    MESSAGE(SQLM.ErrorText())
  END

Observaciones

Deja FreeQueue = True y State = SQL:Ready. Guarda la cadena en PropOwner.

Respecto de SQLClass6

Método nuevo: no existe en la SQLClass6.
