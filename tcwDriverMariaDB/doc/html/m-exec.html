SQLMariaClass > Ejecutar consultas

SQLMariaClass.Exec

Exec(STRING Query),BYTE

Envía una consulta al servidor. Si es un SELECT, deja el resultado listo para leer con Next / Col / LoadQueue.

Como en la SQLClass6, pasa toda la consulta a minúsculas antes de enviarla (incluidos los valores entre comillas), salvo que KeepCase = True. Después la analiza con Parse y la envía.

Parámetros

ParámetroDescripción
Queryla sentencia SQL (SELECT, INSERT, UPDATE, DELETE, CALL, SHOW...).

Devuelve

Level:Benign (0) si salió bien; Level:Notify (1) si hubo un error (el texto queda en ErrorText()).

Ejemplo

  SQLM.KeepCase = True
  IF SQLM.Exec('SELECT IdCliente, Descripcion FROM cbtes WHERE TipoCbte = ''FC''') = Level:Benign
    LOOP UNTIL SQLM.Next()
      ! SQLM.Col(1), SQLM.Col(2)
    END
  END

Observaciones

Con SilentMode = False un error muestra el mensaje del servidor con STOP. Siempre que falla, la consulta queda copiada al portapapeles (también con SilentMode). Con Debug = True avisa si la consulta tardó más de Debug_Limit.

Sin KeepCase, un INSERT ... VALUES ('Juan') graba juan, y en servidores Linux los nombres de tabla con mayúsculas no se encuentran.

Respecto de SQLClass6

Igual que en la SQLClass6.
