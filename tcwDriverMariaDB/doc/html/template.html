Template SQLClass (Motor MariaDB)

El template global SQLClass ("Utilizacion de SQL class para Clarion6", sqlclass6.tpl) declara los objetos SQL de la aplicación. Esta versión agrega dos opciones; todo lo demás queda como estaba.

Opción Motor (por objeto)

En las extensiones globales de la aplicación, SQLClass > Objetos SQL Globales, cada objeto tiene ahora:

PromptValores
MotorDriver de la app (como hasta ahora: SQLOdbcClass / SQLMsClass / SQLIfxClass / SQLOraClass según la base elegida) o MariaDB directo

Un objeto con MariaDB directo (por ejemplo SQLM) se genera así:

SQLM                 &SQLMariaClass
Hide:SQLM            CLASS(SQLMariaClass)

Los embeds de métodos del objeto funcionan igual (con su llamada a PARENT). Si al menos un objeto usa MariaDB, el template agrega también INCLUDE('SQLClass6Maria.inc') y libmariadb.lib al proyecto.

Pasar a MariaDB de a poco

  1. Dejar el objeto SQL como está (Motor = Driver de la app).
  2. Agregar un objeto SQLM con Motor = MariaDB directo.
  3. Inicializarlo con la misma cadena: SQLM.Init(sqlclass,uSQL:Record,GLO:Conexion).
  4. En cada procedimiento que se quiera pasar, cambiar SQL. por SQLM..
  5. En los procedimientos con TCW_Display, poner SQLM en Instancia SQLClass.

Los dos objetos conviven en la misma aplicación. Así se compara el resultado antes de cambiar todo.

TCW_Display llama a Exec, que pasa la consulta a minúsculas. Si la base está en Linux (los nombres de tabla distinguen mayúsculas), poner SQLM.KeepCase = True después del Init.

Opción Usar StringTheory

En Configuración, el check Usar StringTheory (log de la SQLClass) viene tildado. Destildado, el template agrega SQLClass6SinStringTheory=>1 al proyecto: la SQLClass6 no incluye StringTheory y WriteLog escribe el log con la API de Windows (mismo formato). Sirve para aplicaciones que no usan StringTheory.

Aplicaciones existentes

Una aplicación que no usa MariaDB directo y deja tildado Usar StringTheory genera exactamente el mismo código que con el template original (verificado archivo por archivo).

Ejemplo: los dos motores con el mismo código

  SQL.SilentMode  = True
  SQLM.SilentMode = True
  IF SQL.Init(sqlclass,uSQL:Record,L:Conn) = Level:Benign       ! driver de la app (ODBC)
    IF SQL.Exec('SELECT COUNT(*) FROM cbtes WHERE Fecha >= ''2026-01-01''') = Level:Benign AND SQL.Next() = Level:Benign
      MESSAGE('ODBC: ' & SQL.Col(1))
    END
  END
  IF SQLM.Init(sqlclass,uSQL:Record,L:Conn) = Level:Benign      ! MariaDB directo, misma cadena
    IF SQLM.Exec('SELECT COUNT(*) FROM cbtes WHERE Fecha >= ''2026-01-01''') = Level:Benign AND SQLM.Next() = Level:Benign
      MESSAGE('MariaDB: ' & SQLM.Col(1) & ' - servidor ' & SQLM.ServerVersion())
    END
  END
