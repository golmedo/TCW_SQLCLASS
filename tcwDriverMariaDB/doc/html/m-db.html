SQLMariaClass.Db

Propiedad Db (&TCWMariaDB): la conexión directa que usa el objeto. Se crea en el constructor y se libera en el destructor. Sirve para ajustar la conexión o usar lo que SQLMariaClass no expone:

  SQLM.Db.ConnectTimeout = 5                        ! antes del Init
  SQLM.Db.AutoReconnect  = False
  IF SQLM.InitMaria(L:Conn) THEN RETURN.
  IF SQLM.Db.Ping() THEN MESSAGE('Se perdió la conexión: ' & SQLM.Db.LastError).
  L:Version = SQLM.Db.ClientVersion()               ! versión de libmariadb.dll
No ejecutar consultas con SQLM.Db.Query mientras se lee un resultado de SQLM: comparten el resultado.
