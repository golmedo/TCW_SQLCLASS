SQLMariaClass.InsertId

nuevo
InsertId(),LONG

Devuelve el valor AUTO_INCREMENT que generó el último INSERT.

Devuelve

El Id generado; 0 si la última sentencia no generó ninguno.

Ejemplo

  IF SQLM.ExecEx('INSERT INTO pedidos (IdCliente, Fecha) VALUES (' & L:Cliente & ',CURDATE())',1) = Level:Benign
    PED:Id = SQLM.InsertId()
  END

Observaciones

Se reinicia en cada consulta: leerlo inmediatamente después del INSERT.

Respecto de SQLClass6

Método nuevo: no existe en la SQLClass6.
