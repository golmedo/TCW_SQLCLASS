SQLMariaClass.IsNull

nuevo
IsNull(SHORT NroCol),BYTE

Indica si una columna de la fila actual es NULL. Col devuelve '' tanto para NULL como para un texto vacío; con IsNull se distinguen.

Parámetros

ParámetroDescripción
NroColnúmero de columna.

Devuelve

1 si es NULL (o la columna no existe); 0 si tiene valor.

Ejemplo

  IF SQLM.IsNull(4)
    Q:FechaBaja = 0
  ELSE
    Q:FechaBaja = DEFORMAT(SQLM.Col(4),@d10-)
  END

Respecto de SQLClass6

Método nuevo: no existe en la SQLClass6.
