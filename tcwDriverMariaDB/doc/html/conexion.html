Cadena de conexión

La cadena va en Init(...), InitMaria(...) o Db.Connect(...). Son pares clave=valor separados por ;. Las mayúsculas en las claves no importan.

Clave (y sinónimos)ValorPor defecto
Server (Host, Data Source, Address)nombre o IP del servidor127.0.0.1
Portpuerto3306
Database (Db, Initial Catalog)base de datosninguna
User (Uid, User Id, Username)usuario
Password (Pwd)clave
Charset (Character Set)juego de caracteres de la conexiónlatin1
Timeout (Connect Timeout, Connection Timeout)segundos para conectar10
SSL (SslMode, Ssl Mode)1, TRUE, REQUIRED, VERIFY_CA o VERIFY_FULL exige TLS y verifica el certificado0
Server=192.168.0.10;Port=3306;Database=gestion;User=app;Password=****

La cadena de ODBC también sirve

Las claves que no conoce se ignoran, así que la cadena que hoy usa la aplicación con el driver ODBC funciona tal cual:

DRIVER={MySQL ODBC 5.1 Driver};SERVER=192.168.0.10;DATABASE=gestion;UID=app;PWD=****;OPTION=3

Por eso, al pasar un objeto a MariaDB directo desde el template, el Init(archivo, registro, cadena) existente no se toca.

Charset latin1

Con latin1 (el valor por defecto) los textos viajan sin conversión entre Clarion (ANSI / windows-1252) y el servidor: acentos y eñes llegan bien. Cambiarlo solo si la base usa otro juego de caracteres y se convierte a mano.

TLS (SSL)

Connector/C 3.4 exige TLS de fábrica, y los servidores viejos (MySQL 5.0) no lo tienen. Por eso, con SSL=0 (por defecto) la clase usa TLS solo si el servidor lo ofrece, sin exigirlo. Con SSL=1 lo exige y verifica el certificado.

Leer la cadena del INI

L:Conn      CSTRING(1024)
  CODE
  L:Conn = GETINI('Conexion','Cadena','',LONGPATH() & '\MiApp.ini')
  IF SQLM.InitMaria(L:Conn) THEN MESSAGE(SQLM.ErrorText()); RETURN.
