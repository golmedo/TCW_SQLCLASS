SQLMariaClass.BeginTransaction / Commit / Rollback

nuevo
BeginTransaction(),BYTE,PROC
Commit(),BYTE,PROC
Rollback(),BYTE,PROC

Manejan una transacción: BeginTransaction envía START TRANSACTION, Commit confirma los cambios y Rollback los deshace.

Devuelve

Level:Benign (0) si salió bien; Level:Notify (1) si hubo un error (el texto queda en ErrorText()).

Ejemplo

  SQLM.BeginTransaction()
  L:Error = SQLM.ExecEx(L:Sql1,1)
  IF NOT L:Error THEN L:Error = SQLM.ExecEx(L:Sql2,1).
  IF L:Error
    SQLM.Rollback()
  ELSE
    SQLM.Commit()
  END

Observaciones

Solo en tablas InnoDB (en MyISAM no deshacen nada). No pasan por LogFile. Si la conexión se corta en medio de una transacción, la reconexión automática empieza una sesión nueva: la transacción se pierde (el servidor la deshace).

Respecto de SQLClass6

Método nuevo: no existe en la SQLClass6.
