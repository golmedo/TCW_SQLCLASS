SQLMariaClass > Leer resultados

SQLMariaClass.Next

Next(),BYTE,PROC

Avanza a la siguiente fila del resultado. Después se leen las columnas con Col o ColByName. Por cada fila llama al método virtual TakeRecord.

Devuelve

Level:Benign (0) si trajo una fila; Level:Notify (1) si no hay más filas (o no hay resultado).

Ejemplo

  LOOP UNTIL SQLM.Next()
    Q:Codigo = SQLM.Col(1)
    Q:Nombre = SQLM.Col(2)
    ADD(Q)
  END

Observaciones

Suma 1 a Records_Done por cada fila. Para una sola fila: IF SQLM.Exec(...) = Level:Benign AND SQLM.Next() = Level:Benign.

Respecto de SQLClass6

Igual que en la SQLClass6.
