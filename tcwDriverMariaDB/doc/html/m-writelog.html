SQLMariaClass.WriteLog

WriteLog(STRING Text)

Agrega una línea aaaammdd hh:mm:ss.cc texto al archivo indicado en LogFile. La clase la usa para anotar cada consulta; también se puede llamar para anotar líneas propias. Si LogFile está vacío no hace nada.

Parámetros

ParámetroDescripción
Textel texto a anotar.

Ejemplo

  SQLM.LogFile = LONGPATH() & '\sql.log'
  SQLM.WriteLog('Cierre de caja: inicio')

Observaciones

Con StringTheory (por defecto) o, si el template tiene destildado Usar StringTheory, con la API de Windows.

Respecto de SQLClass6

Igual que en la SQLClass6.
