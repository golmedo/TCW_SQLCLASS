SQLMariaClass.Col_Format

Col_Format(SHORT NroCol, STRING Formato)

Indica el picture con que LoadQueue convierte (con DEFORMAT) una columna antes de ponerla en la cola. Se usa sobre todo para fechas y horas, que llegan como texto.

Parámetros

ParámetroDescripción
NroColnúmero de columna.
Formatopicture de Clarion, por ejemplo '@d10-' para aaaa-mm-dd o '@t4' para hh:mm:ss.

Ejemplo

  SQLM.Col_Format(2,'@d10-')
  SQLM.Col_Format(3,'@t4')
  SQLM.LoadQueue(MovQ,0,0)

Observaciones

Los formatos se borran después de cada LoadQueue: indicarlos antes de cada carga. No se aplican a Col().

Respecto de SQLClass6

Igual que en la SQLClass6.
