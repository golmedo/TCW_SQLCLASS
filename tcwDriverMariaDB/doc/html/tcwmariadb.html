Clase TCWMariaDB

TCWMariaDB (TCWMariaDB.inc / .clw) llama a libmariadb.dll por su API pública. Es lo que usa SQLMariaClass por dentro, y se puede usar sola. Devuelve lo mismo que la SQLClass: 0 = bien, 1 = error (detalle en LastError). No pasa nada a minúsculas.

Propiedades

PropiedadTipoUso
Host, Port, User, Password, DatabaseCSTRING / LONGDatos de conexión (los llena SetConnection).
CharsetCSTRING(32)Juego de caracteres; latin1 por defecto.
ConnectTimeoutLONGSegundos para conectar; 10 por defecto.
AutoReconnectBYTE1 (por defecto) = si se cortó la conexión (2006 / 2013), reconecta y reintenta una vez.
SSLBYTE0 = TLS opcional; 1 = TLS obligatorio con verificación del certificado.
LastError, LastErrnoCSTRING, LONGÚltimo error.
AffectedRows, InsertIdLONGDel último INSERT / UPDATE / DELETE (después de un SELECT, AffectedRows = filas del resultado).

Métodos

MétodoDevuelveQué hace
SetConnection(STRING Cadena)Lee la cadena de conexión y llena las propiedades (no conecta).
Connect(<STRING Cadena>)BYTEConecta (con la cadena o con las propiedades). 0 = bien.
Disconnect()Cierra la conexión y libera el resultado.
Connected()BYTE1 si hay conexión abierta.
Ping()BYTEVerifica que el servidor responde. 0 = bien.
Query(STRING Sql)BYTEEnvía la sentencia tal cual y guarda el resultado completo. 0 = bien.
HasResult()BYTE1 si la última sentencia devolvió filas.
Next()BYTESiguiente fila: 0 si trajo una, 1 al final.
Columns()LONGCantidad de columnas del resultado.
RowCount()LONGCantidad de filas del resultado.
Col(LONG n)STRINGValor de la columna n de la fila actual ('' si es NULL).
IsNull(LONG n)BYTE1 si la columna es NULL.
ColName(LONG n)STRINGNombre de la columna n.
ColIndex(STRING Nombre)LONGNúmero de la columna con ese nombre (0 si no existe); no distingue mayúsculas.
FreeResult()Libera el resultado y descarta los pendientes (los de un CALL).
Escape(STRING Texto)STRINGTexto escapado para ir entre comillas.
Quote(STRING Texto)STRINGTexto escapado y entre comillas.
BeginTransaction(), Commit(), Rollback()BYTETransacciones (InnoDB).
ServerVersion(), ClientVersion()STRINGVersión del servidor y de libmariadb.dll.

Ejemplo

Db          TCWMariaDB
  CODE
  IF Db.Connect(L:Conn) THEN MESSAGE(Db.LastError); RETURN.
  IF Db.Query('SELECT COUNT(*) FROM cbtes') = Level:Benign AND Db.Next() = Level:Benign
    MESSAGE(Db.Col(1) & ' comprobantes')
  END
  Db.Disconnect()
