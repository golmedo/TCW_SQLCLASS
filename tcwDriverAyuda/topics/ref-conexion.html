La conexión directa, que se puede usar sola. Propiedades útiles desde la SQLClass como SQL.Db.xxx:

Propiedad / métodoQué hace
BatchSizefilas por envío de InsertarLote / AddRow (500; 0 = solo con EnviarLote)
MaxBatchBytesMariaDB: tamaño máximo de un INSERT de varias filas (512 KB)
PendingRows()filas del lote que faltan mandar
ClientVersion()driver usado (SQL Server: ODBC Driver 17 for SQL Server (msodbcsql17.dll 17.10))
IdentityAfterInsertSQL Server: 1 = un INSERT por Exec deja el IDENTITY en InsertId
AutoReconnect1 = si se cayó la conexión reconecta y reintenta una vez
Driver, Encrypt, ConnectTimeoutSQL Server: driver ODBC, cifrado, tiempo de conexión
Charset, SSL, PortMariaDB

SQL Server: el motor está en tcwmss.c (API de ODBC; odbc32.dll se carga en runtime, sin .lib). MariaDB: libmariadb.dll por su API pública.
