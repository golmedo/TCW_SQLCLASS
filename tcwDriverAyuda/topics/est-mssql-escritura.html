Pantalla Ejemplos de uso, 2.000 filas: INSERT como texto 627 filas/s, Insertar 6.250 (10×), InsertarLote 15.385 (24×).

  • Armar el INSERT como texto en cada fila es lo más lento: el servidor analiza el texto cada vez.
  • Insertar rinde como el driver de Clarion con ADD (los dos preparan la sentencia).
  • InsertarLote: unas 3 veces el driver de Clarion.
  • En tempdb SQL Server no espera a grabar el log en cada confirmación: el efecto de LOGOUT / transacción en una base normal es mayor que el que se ve acá.

Cuidado: la consulta de SQLClass6 tiene un límite de 20.480 caracteres (Query CSTRING(20480)): un INSERT de 500 filas armado a mano no entra. InsertarLote no tiene ese límite.
