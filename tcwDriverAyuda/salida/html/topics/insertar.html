  • Insertar arma INSERT INTO tabla (c1,c2,...) VALUES (?,?,...) con los campos agregados.
  • SQL Server: la sentencia se prepara la primera vez y se reutiliza mientras los campos sean los mismos.
  • El servidor convierte cada valor al tipo de la columna (texto, número, fecha aaaa-mm-dd).
  • SQL Server: SQL.InsertId() da el IDENTITY de un INSERT hecho con Exec (agrega SCOPE_IDENTITY() en el mismo lote); MariaDB: InsertId() después de cualquier INSERT.

Cuidado: un REAL convertido a texto puede salir en notación científica (1.5E+20) y SQL Server no lo acepta para un decimal: para importes usar variables DECIMAL.
