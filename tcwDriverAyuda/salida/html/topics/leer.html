SQLClass directo1.0

Leer datos

MétodoQué hace
Exec(q)ejecuta (pasa la consulta a minúsculas, como SQLClass6)
ExecEx(q,1)ejecuta respetando mayúsculas (recomendado; los valores entre comillas no se tocan)
Next()fila siguiente: 0 = trajo una; distinto de 0 = no hay más
Col(n) / ColByName(nombre)valor como texto (fechas aaaa-mm-dd, decimales con punto)
IsNull(n)1 si el valor es NULL
Columns() / Field(n)cantidad de columnas / nombre real de la columna n
Records()filas del resultado, exacto (también con GROUP BY / DISTINCT): el resultado se lee entero al ejecutar
Col_Format(n,pic) + LoadQueue(Q,0,0)carga la cola campo por campo con DEFORMAT
Fetch(n,q)primer valor de una consulta

Nota: cada consulta se lee entera al ejecutarla (como mysql_store_result): Records() es exacto y la barra de avance tiene total. Una consulta de millones de filas ocupa esa memoria: paginar (ver Carga por páginas).
