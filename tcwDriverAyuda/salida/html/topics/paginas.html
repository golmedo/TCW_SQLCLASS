Carga por páginas

Para listas grandes: se trae una página (por ejemplo 200 filas) y la siguiente cuando el final de lo cargado entra en pantalla. La página siguiente continúa desde la última fila (clave), no usa OFFSET:

  ! primera pagina
  SELECT TOP 200 ... FROM cbtes WHERE <filtro> ORDER BY Fecha DESC, IdTransaccion DESC     ! MySQL: ... LIMIT 200
  ! siguientes: desde la ultima fila cargada
  ... AND Fecha <= 'ult' AND (Fecha < 'ult' OR IdTransaccion < ultId)
  • Se detecta el final con un TIMER y EVENT:NewSelection mirando ?Lista{PROP:YOrigin} + ?Lista{PROP:Items} (anda con la rueda, la barra y el teclado, sin IMM).
  • SQL.FreeQueue = False: LoadQueue agrega a la cola en vez de vaciarla.
  • Guardar la fecha tal como la manda el servidor (columna extra con alias: en SQL Server la misma columna dos veces con ORDER BY por ella da el error 209).
