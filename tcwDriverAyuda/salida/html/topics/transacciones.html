Transacciones

  SQL.BeginTransaction()
  ... Exec / Insertar / InsertarLote ...
  IF error THEN SQL.Rollback() ELSE SQL.Commit().
  • Equivale a LOGOUT / COMMIT / ROLLBACK del driver de Clarion.
  • SQL Server: con la API de ODBC (autocommit apagado hasta Commit / Rollback). Dentro de una transacción no se reconecta solo.
  • MariaDB: la tabla tiene que ser InnoDB (en MyISAM no hay transacciones).
  • Verificado: BeginTransaction + DELETE de 2.000 filas + Rollback deja las 2.000.
