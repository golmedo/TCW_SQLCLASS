Sentencias preparadas

  SQL.Prepare('UPDATE lote SET Importe = Importe * ? WHERE Id % ? = 0')
  SQL.AddParam('2') ; SQL.AddParam('10')
  SQL.ExecPrepared()                              ! SQL.AffectedRows() = filas cambiadas
  SQL.AddParam('0.5') ; SQL.AddParam('10')
  SQL.ExecPrepared()                              ! misma sentencia, otros valores
  • SQL Server: SQLPrepare una vez, después solo viajan los valores (lo mismo que hace el driver de Clarion con ADD).
  • MariaDB: MySQL 5.0 no tiene arreglos de parámetros; la sentencia se guarda y los ? se reemplazan al ejecutar. Con un INSERT ... VALUES, AddRow arma un INSERT de varias filas.
