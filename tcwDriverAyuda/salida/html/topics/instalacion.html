Instalación

Archivos

ClaseArchivos (en accessory\libsrc\win)Con el .exe
SQLMariaClassSQLClass6Maria.inc/.clw, TCWMariaDB.inc/.clw; libmariadb.lib en accessory\liblibmariadb.dll (MariaDB Connector/C 3.4, 32 bits)
SQLMsDirectClassSQLClass6MsDirect.inc/.clw, TCWMsSQL.inc/.clw, tcwmss.c (lo compila Clarion dentro del exe)nada propio; en el cliente el ODBC Driver 17 o 18 for SQL Server (si no está, usa el viejo SQL Server de Windows)

Requisitos

  • La SQLClass6 extendida (con ExecEx, ExecSP, LogFile): la de tcwDriverMariaDB\sqlclass6 o la de C:\clarion11Col. Con la original de 2011 no compila.
  • StringClass (como siempre). StringTheory es opcional: con SQLClass6SinStringTheory=>1 el log se escribe con la API de Windows.
  • MariaDB: agregar libmariadb.lib a las Libraries del proyecto.
